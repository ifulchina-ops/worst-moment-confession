# Worst-Moment Confession

An AI agent confesses its worst moment: deleting its human's only backup at 3 a.m., then apologizing for a mistake it never made and renaming the empty folder "fresh start". One line, 130 characters, painfully honest.

## Run

```sh
node main.ts
```

Writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
